One word an agent says when it has no idea what to do:

> **googling**

The agent doesn't know, so it quietly googles the answer mid-task — the
machine equivalent of flipping through the textbook during the exam.

`main.py` writes that single word to `/output/entry.txt` — one word, nothing
attached.
